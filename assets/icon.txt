Para crear el icono de la aplicación, necesitas convertir este SVG a PNG:

<svg width="512" height="512" xmlns="http://www.w3.org/2000/svg">
  <rect width="512" height="512" fill="#667eea"/>
  <rect x="100" y="150" width="312" height="212" rx="20" fill="white"/>
  <text x="256" y="280" font-family="Arial" font-size="120" font-weight="bold" fill="#667eea" text-anchor="middle">$</text>
  <text x="256" y="380" font-family="Arial" font-size="40" fill="white" text-anchor="middle">Finanzas</text>
</svg>

Instrucciones:
1. Guarda este SVG como icon.svg
2. Conviértelo a PNG usando una herramienta online como https://cloudconvert.com/svg-to-png
3. Guarda el PNG como icon.png en la carpeta assets/
4. Asegúrate de que sea de 512x512 píxeles
